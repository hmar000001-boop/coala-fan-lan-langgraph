# Mermaid diagrams

Future Mermaid source diagrams (`*.mmd`) belong here. Run `bash scripts/render-diagrams.sh` to generate matching SVG and PDF assets under `generated/`. The generated assets are ignored by Git and should be reproducible from the Mermaid source.

The current Chapter 2 conceptual redraws are authored as TikZ directly in the chapter file, using the author's supplied preamble. If the author later chooses to standardize diagrams on Mermaid, they can be migrated here.
